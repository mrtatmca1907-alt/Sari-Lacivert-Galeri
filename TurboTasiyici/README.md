# ATMACA Turbo Görsel Taşıyıcı

Yeni ve bağımsız Android uygulaması. Android 13'te 'Tüm dosyalara erişim' izni ister. Telefonun paylaşılan depolama alanında erişilebilir görselleri `Pictures/ATMACA-Gorseller` klasörüne taşır. Aynı adları +1, +2 ile korur. Önce hızlı rename dener; başarısız olursa kopyalayıp doğruladıktan sonra kaynağı siler. Android/ gibi korunan dizinlere erişemez. İlk çalıştırmadan önce önemli dosyalarınızı yedekleyin. APK GitHub Actions artifact olarak çıkar.
