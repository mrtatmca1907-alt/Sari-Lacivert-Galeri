# ATMACA Görsel Yöneticisi (Windows)

Sarı-lacivert arayüzlü, tek dosyalık Windows EXE.

## Özellikler
- Kaynak ve hedef klasör seçimi
- Yalnızca görsel uzantılarını işler
- Dosya adına göre tam/kısmi arama
- Arama sonuçlarını listeleme ve çift tıklayarak açma
- Seçilenleri, arama sonuçlarını veya kaynak klasördeki tüm görselleri taşıma
- Alt klasörleri tarama seçeneği
- Aynı isimli hedef dosyaların üzerine yazma
- İşlem ilerlemesi ve hata sayacı

## Güvenlik
Taşıma başlamadan önce onay ister ve aynı isimli hedef dosyaların değişeceğini bildirir. Yeni dosya başarıyla hazırlanamazsa mevcut hedef dosyayı değiştirmez. Varsayılan olarak yalnızca kaynak klasörünün ana seviyesini tarar; alt klasörler için kutuyu işaretleyin.

EXE, GitHub Actions tarafından Windows üzerinde derlenir.
